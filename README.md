# 🐸 Dictado Mágico

Web app para que niños practiquen el **dictado de palabras en inglés** (sonidos /sn/, /sm/, /pr/, /fr/, /br/).

## Modos
| Modo | Qué hace |
|---|---|
| 👀 **Aprender** | Tarjetas con dibujo, palabra, significado y pista. Toca cada letra para escucharla. |
| 🧩 **Armar** | Escucha la palabra y arma con letras desordenadas. |
| ⌨️ **Escribir** | Escucha y escribe con un teclado grande en pantalla. |
| ✏️ **Cuaderno** | Igual que la prueba: escribe en papel y luego revisa la respuesta. |

Las palabras falladas se repiten al final. Las estrellas se guardan en el dispositivo.

## Cambiar las palabras
Edita la lista `WORDS` al inicio del `<script>` en `index.html`.

## Publicar en GitHub Pages
Settings → Pages → *Deploy from a branch* → elige la rama y carpeta `/ (root)` → Save.
